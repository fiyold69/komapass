# 決定事項（docs/decisions）

KomaPass（仮）で決めたことと、その理由を置く場所。

**2026年10月13日から、決定の正本はこのフォルダ。** それより前の議論の経緯は、計画ドキュメント（Claude Docs）の「注意点」タブに残っている。食い違ったら、このフォルダを正とする。

| --- | --- |

| [open-questions.md](open-questions.md) | 未決事項（決まるまでの置き場所） |

## 書き方の約束

- 1つの決定には「決定」「理由」「決めた日」を書く
- 決定を変えるときは、本文を直したうえで、そのファイルの「決定の履歴」に1行足す（いつ・何を・なぜ）。古い決定は履歴に残る
- 未決のものは [open-questions.md](open-questions.md) にだけ書く。決まったら該当するファイルに移し、open-questions.md では「決まったこと」に1行だけ残す
- **決定は、PRでmainにマージされたものだけを正とする。** チャットで話しただけのものは「案」
- CLAUDE.md は、AIが毎回読む短い要約。決定を変えるPRでは、CLAUDE.md の該当する行も同じPRで直す
- 確かめきれていないことは「不確か」「要確認」と書き、推測で埋めない
- 塾名・実在の人名・教室名は書かない

## 決定の書式（コピー用）

~~~markdown
### 〈項目名〉

- 決定：〈何に決めたか〉
- 理由：〈なぜか。比べた案があれば一言〉
- 決めた日：2026-10-XX（関連：#Issue番号）
~~~

履歴の書式：

~~~markdown
| 日付 | 内容 | 関連 |
| --- | --- | --- |
| 2026-10-XX | 〈何を決めた・変えた〉 | #番号 |
~~~
