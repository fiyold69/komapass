# ユーザーストーリー（MVP）

## US-01 依頼を出す

講師として、出られないコマの代講を募集したい。
LINEで一人ずつ頼む手間を減らしたいから。

### 完了条件

- [ ] 日付と時限を選んで依頼を出せる
- [ ] 授業開始時刻を過ぎた日時は選べない
- [ ] 出した依頼が、他の講師の一覧に「募集中」で表示される
- [ ] 教室長は依頼を出せない

## US-02 依頼の一覧を見る

講師として、代講を募集している依頼の一覧を見たい。
自分が代われるコマがあるか知りたいから。

### 完了条件

- [ ] 募集中・申し出ありの依頼が、日付・時限・依頼者名つきで日付・時限順（昇順）に表示される
- [ ] 授業開始時刻を過ぎた依頼は表示されない
- [ ] 成立した依頼と取り消された依頼は表示されない
- [ ] 自分が出した依頼は、自分の依頼だと分かる表示になる

## US-03 申し出る

講師として、他の講師の依頼に「代われます」と申し出たい。
個別にやり取りせずに、空いていることを伝えたいから。

### 完了条件

- [ ] 申し出ると、依頼者の画面のその依頼に、申し出た人の名前が表示され、「申し出あり」の状態になる。
- [ ] 自分が出した依頼には申し出られない
- [ ] 同じ依頼に2回は申し出られない
- [ ] 取り消された依頼には申し出られない
- [ ] 授業開始時刻を過ぎた依頼には申し出られない
- [ ] 成立した依頼には申し出られない
- [ ] 教室長は依頼を申し出られない

同時操作系項目

- [ ] 申し出と同時に依頼が成立しても、申し出た人には「先に担当してくださる方がいたようです」と表示される（ケース4）

## US-11 申し出の取り下げ

講師として、自分の申し出を取り下げたい。
申し出たあとに急な用事ができて、出られなくなることがあるから。

### 完了条件

- [ ] 取り下げると、依頼者の画面から名前が消える
- [ ] 他人の申し出は取り下げられない
- [ ] 授業開始時刻を過ぎた依頼は取り下げられない
- [ ] 申し出が0件になったとき、状態は「申し出あり」から「募集中」に戻る
- [ ] 成立した後は、取り下げられない

## US-04 申し出た人から選んで成立させる

依頼した講師として、申し出てくれた人の中から1人を選んで代講を決めたい。
誰に任せるかを自分で決めたいから。

### 完了条件

- [ ] 自分の依頼に申し出た人の一覧から1人を選ぶと、依頼が「成立」になる
- [ ] 選ばれた人の画面に、その代講が自分の担当として表示される
- [ ] 選ばれなかった人には「先に担当してくださる方がいたようです」と表示される
- [ ] 他人の依頼では選べず、成立した後は選び直せない
- [ ] 申し出ていない人は選べない
- [ ] 授業開始時刻を過ぎた依頼は選べない

同時操作系項目

- [ ] 「選ぶ」を続けて2回押しても、成立は1回だけで、エラー画面にはならない（ケース1）
- [ ] 別々の画面で2人をほぼ同時に選んでも、成立するのは1人だけ（ケース8）
- [ ] 選ぶのと取り消すのがほぼ同時でも、依頼は「成立」か「取り消し」のどちらか一方になる（ケース7）
- [ ] 授業開始時刻の直前に選んでも、サーバーに届いた時点で開始時刻を過ぎていれば、成立しない（ケース6）

## US-05 依頼を取り消す

依頼した講師として、出した依頼を取り消したい。
自分で出られるようになることがあるから。

### 完了条件

- [ ] 募集中・申し出ありの依頼を取り消せる
- [ ] 申し出ていた人には「依頼が取り消されました」と表示される
- [ ] 成立した依頼は取り消せない
- [ ] 他人の依頼は取り消せない
- [ ] 授業開始時刻を過ぎた依頼は取り消せない

同時操作系項目

- [ ] 「取り消す」を続けて2回押しても、取り消しは1回だけで、エラー画面にはならない（ケース2）
- [ ] 取り消しと同時に誰かが申し出ても、その人には「依頼が取り消されました」と表示される（ケース5）

## US-06 メールとパスワードでログインする（MVPの後 #23）

講師として、メールアドレスとパスワードでログインしたい。
自分の依頼や担当を、他の人に操作されないようにしたいから。

### 完了条件

- [ ] 正しいメールとパスワードでログインでき、自分の名前が表示される
- [ ] 間違っているとログインできず、メールとパスワードのどちらが違うかは表示されない
- [ ] ログアウトすると、ログインが必要な画面は見られない
- [ ] 初めてログイン（サインイン）した人は承認待ちになる

## US-07 承認待ちの人を承認する

教室長として、新しく登録した人を確認してから使えるようにしたい。
塾と関係のない人に情報を見られたくないから。

### 完了条件

- [ ] 承認待ちの人の一覧が、教室長と開発者の画面に表示される
- [ ] 承認すると、その人は通常どおり使えるようになる
- [ ] 承認待ちの人は、依頼の一覧を含めてどの画面も使えない
- [ ] 講師は承認できない
- [ ] 講師と教室長は役割を変えられない（役割は開発者がスクリプトで付ける。役割を付ける画面はMVPの後）

## US-08 LINEでログインする

講師・教室長として、LINEアカウントでログインしたい。
新しいパスワードを覚えたくないから。

### 完了条件

- [ ] 「LINEでログイン」からログインできる
- [ ] 初めてLINEでログインした人は承認待ちになる
- [ ] 承認された人は、次からLINEだけで使える

## US-09 成立した代講を一覧で見る

教室長として、成立した代講を一覧で見たい。
誰がどのコマに入るのかを把握したいから。

### 完了条件

- [ ] 成立した代講が、日付・時限・依頼した講師・代わる講師つきで一覧表示される
- [ ] 募集中・申し出ありの依頼は出ない
- [ ] 講師はこの画面を使えない

## US-10 利用を止める（MVPの後 #15）

教室長として、辞めた講師がアプリを使えないようにしたい。
塾の情報を見られる人を、今いる講師だけにしたいから。

### 完了条件

- [ ] 教室長が利用を止めると、その人は次にアクセスしたときから使えなくなる
- [ ] 止めた人がこれまでに出した依頼や成立の記録は残る
- [ ] 講師は他の人の利用を止められない
